[`worldmonitor`](https://www.npmjs.com/package/worldmonitor) is the official command-line client for the World Monitor global-intelligence platform. Run it with no arguments and it opens a full **terminal dashboard**: the same news, markets, conflict, military, cyber, climate, prediction, live-video and intel data the web dashboard shows, with mouse support, six colour themes and animations, and no API key required. Its scripting commands are a thin, **dependency-free** wrapper over the [MCP server](/mcp-overview) (the recommended agent surface) with a REST escape hatch, so you can pull briefs, risk scores, and conflict / cyber / market / news feeds from a shell script or an agent without writing a single line of HTTP plumbing. It ships as ESM and runs on **Node 18+**.

The source lives in [`cli/`](https://github.com/koala73/worldmonitor/tree/main/cli) in the main repository and is published to npm on every `cli-v*` release tag.
Maintainers can follow the [CLI release runbook](/releasing-cli) when cutting a new npm version.
Prefer a library over a shell? The same client ships as [official SDKs](/sdks) for **Python**, **Ruby**, and **Go**.

## Install

```sh
npm install -g worldmonitor    # installs the `worldmonitor` command (alias: `wm`)
# or run ad-hoc without installing:
npx worldmonitor tools
```

## Terminal dashboard

```sh
worldmonitor          # open the dashboard (alias: worldmonitor tui)
worldmonitor web      # open the original web dashboard
```

The dashboard reads the public bootstrap tiers (`/api/bootstrap?tier=fast&public=1`, `?tier=slow&public=1`), the public news digest and the compact health endpoint, so it works without a key. Military flights and vessel snapshots use an anonymous session token, exactly as the browser does. When `WORLDMONITOR_API_KEY` is set it is sent instead.

| Key | View | Contents |
|---|---|---|
| `1` | Overview | Braille world map with live blips and a radar sweep, AI world brief, ranked top stories, market strip, theater posture |
| `2` | News | 18 digest sections with ranked, threat-classified headlines and a story detail pane |
| `3` | Markets | Indices, commodities, FX and crypto with sparklines, sector heatmap, macro signals, fear & greed, ETF flows, stablecoins, Gulf markets |
| `4` | Conflict | Country instability (CII) ranking, UCDP armed-conflict events, unrest signals, theater posture, correlation cards and cross-source signals |
| `5` | Air & Sea | Live military aircraft on the map, airport delays, chokepoints, vessel density zones, shipping stress and freight indices |
| `6` | Cyber | Threat indicators, DDoS protocol and vector mix, service status, internet outages and traffic anomalies |
| `7` | Climate | Earthquakes, hazards and disease outbreaks, weather alerts, climate anomalies, CO₂ / sea ice / sea level vitals |
| `8` | Predict | Prediction markets by domain and AI scenario forecasts with cascades |
| `9` | Live | The dashboard's live news channels and webcams, played in the terminal |
| `0` | Intel | GDELT topic feeds, sanctions pressure, travel advisories, social velocity, US spending awards, tech events |
| `Tab` | System | Platform health, per-source freshness and refresh, theme picker, player status |

**Controls.** `Tab` / `Shift+Tab` or the number keys switch views; `←` `→` (or `h` `l`) move between panes; `↑` `↓` (or `j` `k`), `PgUp` / `PgDn`, `g` / `G` move in lists; `Enter` opens the selected item; `o` opens its link in the browser; `[` `]` change the News section or Live region; `t` cycles themes and `T` opens the picker; `a` toggles animations; `r` refreshes the current view; `W` opens the web dashboard; `?` shows help; `q` quits. Tabs, rows and buttons are clickable and the mouse wheel scrolls lists.

**Themes.** Neon Horizon (default), Matrix, Amber CRT, Red Alert, Glacier and Synthwave. The choice and the animation toggle persist in `$XDG_CONFIG_HOME/worldmonitor/tui.json` (never credentials). Flags: `--theme <id>`, `--no-anim`, `--fps <n>` (default 20), `--base-url <url>`.

**Live video.** Streams play through [mpv](https://mpv.io) (`brew install mpv yt-dlp`). `Enter` plays inside the terminal: pixel video through the Kitty graphics protocol on Ghostty, Kitty, WezTerm and Konsole, truecolor cells (`--vo=tct`) elsewhere and inside tmux. `w` opens an mpv window and `b` the browser; without mpv the browser is used. Sources follow the dashboard's catalog: the broadcaster's HLS stream first, then YouTube, with channel entries resolved through the `liveVideoResolved` key. `s` cycles sources.

**`worldmonitor web`.** Inside a repository checkout it runs `npm run dev` and opens the printed local URL; elsewhere it opens `https://www.worldmonitor.app/dashboard`. Flags: `--hosted` (skip the checkout), `--port <n>`, `--no-open`, `--url <url>`.

## First call — no key needed

`tools` lists every MCP tool and is **public**, so it's the fastest way to confirm the CLI reaches the API:

```sh
worldmonitor tools
```

You'll get the complete live tool registry back as JSON. Everything else that returns *data* is a `tools/call` and needs a user API key.

## Authenticate

Data commands map to MCP `tools/call`. Except for `worldmonitor call get_sources`, they require a subscription API key. Grab one at [worldmonitor.app/pro](https://www.worldmonitor.app/pro), then either pass it per-call or export it once:

```sh
export WORLDMONITOR_API_KEY=wm_xxxxxxxx
worldmonitor risk IR                       # reads the key from the environment
# — or —
worldmonitor risk IR --api-key wm_xxxxxxxx # pass it explicitly
```

The key is sent as the `X-WorldMonitor-Key` header. See [Authentication](/usage-auth) for how keys, OAuth, and browser sessions differ, and [Rate Limits](/usage-rate-limits) for the per-plan allowances. If you call a subscription-gated data command with no key, the CLI exits `1` and prints a hint telling you exactly which flag to pass.

## Data commands

Ergonomic shortcuts over the highest-traffic tools. Positional arguments (like an ISO country code) and any `--key value` pair flow straight through as tool arguments:

| Command | MCP tool | Notes |
|---|---|---|
| `world` | `get_world_brief` | Live global situation brief |
| `country <ISO>` | `get_country_brief` | AI strategic brief (ISO 3166-1 alpha-2) |
| `risk <ISO>` | `get_country_risk` | Country risk / resilience scores |
| `markets` | `get_market_data` | Equities, commodities, crypto, FX |
| `conflicts` | `get_conflict_events` | `--country`, `--min_fatalities`, `--limit` |
| `cyber` | `get_cyber_threats` | `--min_severity`, `--threat_type`, `--country` |
| `news` | `get_news_intelligence` | `--topic`, `--country`, `--alerts_only` |
| `disasters` | `get_natural_disasters` | `--dataset`, `--active_only`, `--min_magnitude` |
| `sanctions` | `get_sanctions_data` | `--country`, `--entity_type`, `--query` |
| `forecasts` | `get_forecast_predictions` | `--domain`, `--region` |
| `maritime <ISO>` | `get_maritime_activity` | Port / vessel activity for a country |

```sh
worldmonitor country IR                              # AI strategic brief
worldmonitor conflicts --country IR --limit 5        # recent conflict events
worldmonitor markets --asset_class crypto            # crypto quotes
```

## Any tool, any argument

The curated table stays small on purpose — every registered tool is reachable via `call`, and any unrecognised `--key value` becomes a tool argument, so nothing needs special wiring:

```sh
worldmonitor call get_cyber_threats --min_severity 7
worldmonitor call get_market_data --args '{"symbols":["AAPL","MSFT"]}'   # typed JSON args
worldmonitor prompts        # list pre-built workflow prompt templates
worldmonitor resources      # list addressable resource URIs
```

Use `--args '<json>'` when you need typed (non-string) arguments; otherwise `--key value` pairs are collected as strings.

<Tip>
Every tool accepts a universal `jmespath` argument that projects the response **server-side** before it crosses the wire — typically 80–95% smaller. The CLI forwards it like any other argument:

```sh
worldmonitor markets --jmespath 'data."stocks-bootstrap".quotes[?symbol==`AAPL`].{s:symbol,p:price}'
```

See the [JMESPath guide](/mcp-jmespath) for 12 worked examples.
</Tip>

## REST escape hatch

For host-relative paths, self-hosted deployments, or the OpenAPI catalog:

```sh
worldmonitor health --api-key wm_xxx      # API status / health check (needs a key)
worldmonitor get /api/cyber/v1/list-cyber-threats --api-key wm_xxx
worldmonitor list cyber                   # list documented REST operations from the live spec
```

`health` maps to the auth-gated [platform health endpoint](/health-endpoints), so it requires `--api-key`. `list` reads the public [OpenAPI spec](/api-reference) and needs no key.

## Flags

| Flag | Purpose |
|---|---|
| `--api-key <key>` | User API key (or env `WORLDMONITOR_API_KEY`) |
| `--mcp-url <url>` | MCP endpoint (default `https://worldmonitor.app/mcp`) |
| `--base-url <url>` | REST base (default `https://api.worldmonitor.app`) |
| `--args <json>` | Typed arguments object for a tool call |
| `--timeout <ms>` | Request timeout (default `30000`) |
| `--theme <id>`, `--no-anim`, `--fps <n>` | Dashboard appearance (`tui`) |
| `--hosted`, `--port <n>`, `--no-open`, `--url <url>` | `web` command options |
| `--raw` | Print the response body verbatim |
| `--compact` | Print single-line JSON |
| `-h, --help` · `-v, --version` | Help / version |

## Exit codes

| Code | Meaning |
|---|---|
| `0` | Success |
| `1` | Request or transport error (response body written to stderr) |
| `2` | Usage error (bad command or missing required argument) |

Predictable exit codes make the CLI safe to drive from shell pipelines and CI.

## Programmatic use

The same logic is importable — handy for embedding in a Node script without shelling out:

```js
import { run } from 'worldmonitor/run';

const code = await run(['risk', 'IR'], { env: process.env });
```

`run()` takes an injectable IO bag (`fetch`, `env`, `stdout`, `stderr`), so it's fully testable offline, and returns the numeric exit code.
